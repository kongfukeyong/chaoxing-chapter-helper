# 超星章节作业助手

Windows 桌面工具，处理当前打开的超星章节作业。连接专用 Edge 后，在作业页面点击“快速处理当前页”，程序读取可见题目、调用用户配置的 AI 服务并填写答案。题目全部填写成功后可自动提交。

## D 盘便携版

1. 双击 `start.cmd`。首次启动填写自己的 AI API Key、接口地址和模型。
2. 在打开的 Edge 中登录超星，完成验证，再点击“连接浏览器”。
3. 打开章节作业，等待题目显示，点击“快速处理当前页”。
4. 根据需要切换“自动提交”按钮，然后处理当前页或整个课程目录。

在课程学生学习页可点击“处理整个课程目录”。程序会在专用 Edge 中找到学习页标签，逐项打开目录，并遍历每节的“视频”“章节测验”等内页；点击网页播放器开始视频，在平台标记完成后处理下一任务；填写已加载的作业题目，全部填写成功后自动提交。目录未全部完成时会每隔 15 秒重新检查未完成任务，直到全部完成或手动点击“停止”。观看时专用 Edge 会切到前台。平台视频与作业的最终完成状态以网页显示为准。

可点击“暂时断开”，完成手动操作后再点“重新连接”。“按大题独立对话”逐题组调用 AI，“整页一次处理”将当前页题目放在一次请求中。

程序识别嵌套 iframe 内的 `.TiMu` 或 `.questionLi` 容器，支持超星的可点击选项、文本输入；视频按正常播放进度等待结束。已在登录后的超星测验页验证题目识别、填写、提交确认与平台完成状态，并持续观察完成状态约两分钟。目录切换另有本机页面测试。提交结果以网页显示为准。

## 源码运行

准备 Python 3.12、Edge 和 FFmpeg，安装 `requirements.txt` 后运行 `python app.py`。Windows 便携版自带运行时和驱动。

API Key 仅写入本机 `config.json`；专用浏览器资料位于 `data/edge-profile`。这些目录和文件被 `.gitignore` 排除。

程序启动时会向 `https://infox.kongfu.xyz/` 发送一次固定请求，统计启动次数。请求不附带账号、API Key 或设备 ID；Cloudflare 的常规访问日志可能包含 IP 和 User-Agent。可在 `config.json` 中将 `usage_ping` 设为 `false` 关闭此请求。
